### 2. New Reward: Flanking Separation (`go1_push_vel_wrapper.py`)

**Purpose:** Reward agents for being on DIFFERENT faces of the box (~90° apart) instead of clustering on the same face.

**Mechanism:** 2D cross product of normalized agent-to-box vectors:
```python
cross_mag = |cross(normalize(agent0-box), normalize(agent1-box))| = sin(angle_between)
```
- Same face (0°): cross_mag ≈ 0 → no reward
- Adjacent faces (90°): cross_mag = 1.0 → max reward
- Opposite faces (180°): cross_mag ≈ 0 → no reward

**Scale:** 0.002 per step (max). ~4% of typical tracking reward — gentle positioning nudge.

**Files:** Config scale in `go1_push_vel_config.py`, computation + buffer + init print in `go1_push_vel_wrapper.py`.

### 3. OCB Conditioned on Separation (`go1_push_vel_wrapper.py`)

**Problem:** OCB reward ("be behind box") gave full credit even when both agents stacked on the same face shoulder-to-shoulder. No signal to spread apart.

**Fix:** Multiply OCB by cross_mag:
```python
# BEFORE:
ocb_i = -raw_dot * self.velocity_ocb_scale

# AFTER:
ocb_i = -raw_dot * self.velocity_ocb_scale * cross_mag
```

Now agents only get OCB credit when they're behind the box AND spread apart. Same face → cross_mag ≈ 0 → no OCB regardless of being "behind" the box.

**cross_mag computed once** at top of reward section, reused by both OCB and flanking reward (no duplicate math).

### 4. Contact-Force Monitoring Decoupled from Gating (`go1_push_vel_wrapper.py`)

**Problem:** When `--contact_force_gating` flag was off, all force contribution metrics (balance, gate, per-agent contributions) were 0 in TensorBoard — no visibility.

**Fix:** Always compute balance/contributions/gate for monitoring. Only apply gate multiplication to reward when `--contact_force_gating True`:
```python
# BEFORE:
if self.contact_force_gating:
    balance, contribs = self._compute_dual_push_balance()
    gate = ...
    vel_track_reward = vel_track_reward * gate  # gating + logging together
    # log metrics

# AFTER:
balance, contribs = self._compute_dual_push_balance()  # always compute
gate = ...
if self.contact_force_gating:
    vel_track_reward = vel_track_reward * gate          # only gate when flag set
# always log metrics
```

Now `avg_dual_push_balance`, `avg_dual_push_gate`, `avg_push_contribution_agent{i}` always appear in TensorBoard regardless of gating flag.

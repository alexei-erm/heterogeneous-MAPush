## Bugs Found & Fixed

### 1. Arrow marker not visible — `_fix_npc_base_link = True` (ROOT CAUSE)
- Target NPC (used as direction arrow) inherited `_fix_npc_base_link = True` from mid-task config
- Fixed joint prevented `set_actor_root_state_tensor_indexed` from teleporting it
- Fix: Override in velocity config: `_fix_npc_base_link = False`, `_npc_gravity = False`
- File: `mqe/envs/configs/go1_push_vel_config.py`

### 2. Box disappearing — Isaac Gym GPU pipeline buffered state issue (CRITICAL)
- `set_actor_root_state_tensor_indexed` is buffered in GPU pipeline — a second call before `simulate()` REPLACES the first
- `_reset_root_states()` queued ALL actors, then wrapper's `_update_arrow_marker()` queued ONLY target actor → box/agent reset states were lost → box reverted to creation pose `[env_origin]` and fell through terrain
- Fix: Changed `_update_arrow_marker()` to push ALL actors via `actor_indices` (not just target), preserving pending reset states
- File: `mqe/envs/wrappers/go1_push_vel_wrapper.py`

### 3. Stale `root_states_npc` reads
- `root_states_npc` is a COPY of `all_root_states` (non-contiguous slice + reshape), not a view
- Arrow marker was reading stale box positions from this copy
- Fix: Read box position from `all_root_states` directly (live physics tensor)
- File: `mqe/envs/wrappers/go1_push_vel_wrapper.py`

### 4. MAPPO `batch_rewards()` crash — undefined `self.num_envs`
- `mqe_openrl_wrapper` used `self.num_envs` which doesn't exist on the class
- Fix: Changed to `self.env.num_envs`
- File: `openrl_ws/utils.py` line 102

### 5. Calculator test mode incompatible with velocity task
- `test.py` calculator uses `init_finished_buf`, `collision_degree_buf` etc. which don't exist on velocity wrapper
- Would crash at end of training run
- Fix: Removed calculator from `task/velocity/train.sh`, added note about tensorboard metrics
- File: `task/velocity/train.sh`

## Key Technical Insight
**Isaac Gym GPU pipeline**: `set_actor_root_state_tensor_indexed` is a buffered command. Multiple calls before `simulate()` don't merge — the last call REPLACES all previous ones. Any wrapper that modifies actor states after `_reset_root_states()` must include ALL actors in its `set_actor_root_state_tensor_indexed` call, not just the ones it changed.

### Observation spaces
- **Actor**: 16 dims, agent-centric (egocentric). cmd(3) + box_pos(3) + box_vel(3) + self_vel(2) + other_pos(3) + other_vel(2)
- **Critic**: 18 dims, box-centered. cmd(3) + box_dynamics(3) + agent0(5) + agent1(5) + vel_error(2)

### Reward terms (all team rewards)
| Reward | Scale | Purpose |
|--------|-------|---------|
| velocity_tracking | 0.01 | cos_sim(actual,desired) * exp(-speed_err) |
| angular_velocity_penalty | -0.005 | -\|box_wz\| — cooperation mechanism |
| velocity_ocb | 0.004 | Be on push side of box |
| approach | 0.00075 | Stay close to box |
| collision | -0.001 | Agent-agent collision |
| push | 0.0015 | Binary: box moving > 0.1 m/s |
| exception | -5 | NaN/Inf detection |

### Monitoring metrics (not reward signals)
| Metric | What it measures | Target |
|--------|-----------------|--------|
| avg_direction_error | Angle between actual & desired velocity (rad) | → 0 |
| avg_speed_error | \|actual_speed - cmd_speed\| (m/s) | → 0 |
| avg_box_angular_vel | \|box_wz\| (rad/s) | → 0 (cooperation) |

### `root_states_npc` is a COPY, not a view
`self.all_root_states.view(N, -1, 13)[:, num_agents:, :].reshape(-1, 13)` — the slice on a view creates a non-contiguous tensor, and reshape on non-contiguous creates a COPY. Always read/write box positions from `all_root_states` directly for live physics data. Sync back to `root_states_npc` copy manually if needed by observation/reward code.

% Paragraph: Why using agent-local observations as HAPPO critic input is wrong
% Insert where appropriate in the critic representation section

The initial HAPPO setup reused the same critic input as MAPPO: each agent's
ego-centric 8-dimensional observation. In MAPPO this works because parameter
sharing means the critic processes both agents' observations independently and
produces per-agent value estimates. In HAPPO, however, the critic is a
\emph{single centralized} value network $V(s)$ that must estimate the
\emph{team} return from a shared state. In EP mode, this critic only receives
Agent~0's local observation $o_0$ as its input. Since $o_0$ is ego-centric, two
joint states that look identical from Agent~0's perspective but differ in
Agent~1's position yield the same value prediction, even though the expected
team return may be very different (e.g.\ Agent~1 pushing vs.\ Agent~1 far
away). This directly corrupts the TD-error used to train the critic:
%
\begin{equation}
  \delta_t = r_t + \gamma\, V(o_0^{t+1}) - V(o_0^{t})
  \label{eq:td_error_broken}
\end{equation}
%
Here $r_t$ is the team reward, which depends on \emph{both} agents' actions and
positions, but $V$ only sees Agent~0's local view. When Agent~1 contributes
heavily to a high $r_t$, the critic attributes that return to $o_0$ and
over-estimates the value of states where Agent~0 happens to be in a similar
pose---regardless of what Agent~1 is doing. Conversely, when Agent~1 freeloads
and $r_t$ is low, the critic under-estimates states that are actually
favorable from Agent~0's side. The result is a value function that fails to
converge: in practice, the critic loss increased from 0.10 to 0.19 over
training instead of decreasing, because the same input was associated with
contradictory targets depending on Agent~1's unseen behavior. The correct
formulation uses a true global state $s$ that captures all agents:
%
\begin{equation}
  \delta_t = r_t + \gamma\, V(s_{t+1}) - V(s_t), \qquad
  s = [\,\mathbf{x}_{\text{box}},\; \mathbf{x}_{\text{target}},\;
       \mathbf{x}_0,\; \dot{\mathbf{x}}_0,\;
       \mathbf{x}_1,\; \dot{\mathbf{x}}_1\,]
  \label{eq:td_error_correct}
\end{equation}
%
With the full state, each distinct joint configuration maps to a unique critic
input, eliminating the aliasing problem and allowing the TD-error to provide a
consistent learning signal. This change alone---from 8-dim ego-centric input to
a proper global state---was the most impactful modification in the project, as
discussed in section~\ref{sec:happo_critic}.

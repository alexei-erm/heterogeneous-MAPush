Branch: `high-level-happo-task_implementation` (branched from `velocity-MAPush`). Continuing from 3/25 pivot — implementing upper-level (high-level planner) task training with HAPPO via HARL. This is the hierarchical control pipeline: upper → mid → locomotion.

## Architecture: Hierarchical 2-Level Control

```
Upper Level (HARL HAPPO, this session)
  → outputs 2D sub-goal waypoints (x, y)
    Mid Level (frozen HAPPO actors, loaded from checkpoint)
      → outputs 3-DOF velocity commands [vx, vy, vyaw]
        Locomotion Policy (Walk-These-Ways / legged_gym)
          → outputs joint torques
```

- **Upper level**: 1 HARL agent, 26-dim obs, 2-dim action
- **Mid level**: 2 frozen HAPPO actors (per-robot), 8-dim obs, 3-dim action
- **Frozen mid-level**: loaded with `eval()`, called under `torch.no_grad()`

## Design Decisions

| Decision | Choice | Rationale |
|----------|--------|-----------|
| Number of upper-level agents | 1 (single planner) | 26-dim obs already encodes both robots, box, obstacles, trajectory |
| Mid-level checkpoint source | CLI flag at runtime | Flexibility to swap different mid-level checkpoints |
| Episode length | 160s (keep existing) | Upper task already configured for longer horizons |
| Obs dimension fix | 8 not 9 | Actual tensor: target_xy(2) + box_xy(2) + box_yaw(1) + other_agent(3) = 8 |
| Global state for critic | = observation (26d) | Already contains all global info (both robots, box, obstacles, trajectory waypoint) |

## Upper Task Observation (26 dims)
```
base_info (12): [pos_x, pos_y, pos_z, roll, pitch, yaw] × 2 agents
target_pos (2): [x, y] relative to env origin
box_pos (2): [x, y] relative to env origin
box_rot (4): quaternion [qx, qy, qz, qw]
obs1_pos (2): obstacle 1 [x, y]
obs2_pos (2): obstacle 2 [x, y]
waypoint (2): next trajectory planning position [x, y]
```

## Upper Task Rewards
| Reward | Scale | Description |
|--------|-------|-------------|
| `reach_target_reward` | 2.0 | Binary bonus when box reaches final target |
| `distance_to_target_reward` | 0.3 | `1/(1+dist)` — inverse distance box→target |
| `trajectory_rewards` | 0.5 | `1/(1+dist)` — sub-goal proximity to trajectory waypoint |
| `exception_punishment` | -0.5 | NaN/Inf obs or env exceptions |
| `obstacle_reward` | -0.1 | Penalty for sub-goals near obstacles |
